**One-Liner Laughs** — one line, one hissing container, one pact of silence:

> I opened a Tupperware from the back of the fridge. It hissed. I closed it, put it back, and we agreed never to speak of it.

123 characters, one line. It won a 66-game pairwise tournament over 12
candidates in empty lanes (DESIGN.md).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`
with no trailing newline. No clock, no randomness, no network.
